# c-algorithm-circle-perimeter
**Calculadora da Área de um Perímetro**

Aplicação em C que faz o cálculo do IMC a partir da altura e massa corporal.

## 02. Tecnologias Utilizadas
- C18

## 03. Como Instalar e Executar
Executar através de **IDEs** instaladas na sua máquina ou de compiladores on-line, como o [OneCompiler](https://onecompiler.com/).

## 04. Exemplo de Uso ou Demonstração
Utilizando como exemplo, os valores de massa corporal = 70 kg e altura = 1.80 m.
```
Qual a massa corporal da pessoa em kg: 70
Qual é a altura da pessoa em metros: 1.80
O índice da massa corporal é 21.60 kg/m². 
Você está no peso adequado.
```
